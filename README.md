# forecast-project-F25
This repo contains a forecast analysis done on the economic variable `Job Losers as a Percent of Total Unemployed`. Included is the final do-file and the written report done as part of the project. This was a final project for Econ 460: Economic Forecasting at UW-Madison during the Fall 2025 semester.

To run the Stata code: 
1) Download the respective data files
2) Move them to the same directory as `forecast_project.do`
3) In the do-file update the line `global proj_dir "your-project-directory"` accordingly 

## Data

The data used can be found and downloaded at the following links.

* https://fred.stlouisfed.org/series/LNS13023622
* https://fred.stlouisfed.org/series/USRECM
* https://fred.stlouisfed.org/series/AAA
* https://fred.stlouisfed.org/series/BAA
* https://fred.stlouisfed.org/series/GS1
* https://fred.stlouisfed.org/series/GS10
* https://fred.stlouisfed.org/series/TB3MS
